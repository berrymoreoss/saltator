# MOS 6502

Track `MOS` of the [roadmap](../roadmap.md).

**Goal:** M4 "6502 Hello World" — a pin-level, cycle-accurate W65C02S with its companion chips
and a toolchain in the app, until Ben Eater's 6502 computer prints to its LCD from code assembled
in the app.

**Not here:** general parts the systems use (memories, 74HC logic, the LCD — [Parts](parts.md));
general debugger features ([Platform](platform.md)).

## R17a · W65C02S CPU — `feat/cpu-6502`

R17 (the CPU, its state panel and disassembly) was split at its start into the part (R17a) and
its tools (R17b), as R12 was into the memory chips and their inspector: a pin-level,
cycle-accurate CPU and its verification are a branch of their own.

Pin-level, cycle-accurate WDC W65C02S (DIP-40, the 5 V column): PHI2, RWB, A0–A15, D0–D7, IRQB,
NMIB, RESB, RDY (bidirectional: WAI pulls it low), SYNC, VPB, MLB, BE, SOB, PHI1O/PHI2O; every
opcode with the bus cycles the chip makes, checked against SingleStepTests; the data sheet's bus
timing and requirements; unknown bits through the registers, a lost CPU until reset; power-on
unknown until RESB; its registers through a `cpu` inspection interface; the examples 6502 NOP
Sled and a program from ROM. Plan: [feat-cpu-6502](../../.ai/plans/feat-cpu-6502.md).

## R17b · CPU state panel & disassembly — `feat/cpu-6502-tools`

The tools for a CPU in the circuit: a CPU tab (registers, flags, the current instruction and
cycle, live while simulating), disassembly in the memory inspector (an origin per memory, the
program counter marked), Step Instruction in the debugger (to the next opcode fetch), CPU
registers in watches and test benches.

## R18 · Peripherals — `feat/peripherals`

W65C22 VIA (ports, timers, interrupts), 6551 ACIA + serial terminal panel, buzzer (Web Audio),
keypad/matrix keyboard. The HD44780 LCD came early, off the roadmap
([LIB-1](parts.md)); the VIA drives it in R20.

## R19 · 6502 assembler & flashing — `feat/toolchain`

Built-in assembler (ca65/vasm-compatible subset), listing and symbol map, "assemble & flash to
ROM", symbols in debugger.

## R20 · Ben Eater 6502 reference build — `example/be6502`

65C02 + 28C256 + 62256 + 65C22 + LCD with 74HC00 address decoding, running "Hello, world!".
