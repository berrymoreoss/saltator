# src/library — component library

Definitions of parts: pinout, package, properties, timing (with datasheet source), symbol
geometry as data, and behavior written against the `core` component API.

Layout: `primitives/` (`prim/*`, R01), `io/` (`io/*`, R03: rails, contacts, LEDs, displays,
clock, probe), `74xx/` (`74xx/*`, R06: 74HC gates and bus buffers — `ChipSpec` per function,
`LogicFamily` timing, pinouts written like data sheet tables; R08: MSI decoders, multiplexers,
adder, comparator, encoders, 4511, with per-path delays in `paths.ts`; R09a: flip-flops in
`flip-flops.ts` and registers in `registers.ts` on the helpers of `edge-triggered.ts`, with the
core timing checks; R09b: counters in `counters.ts` (161, 163), `up-down-counters.ts` (191, 193)
and `ripple-counter.ts` (4040), shift registers in `shift-registers.ts` (164, 165, 595)),
`timer/` (`timer/*`,
R08: the behavioral NE555), `net/` (`net/*`: R10a the schematic-only net label, which is a
bus label when named like a bus; R10b the bus entry) and
`mem/` (`mem/*`, R12a: EEPROMs read as ROMs in `eeproms.ts`, SRAMs in `srams.ts`, on the read
path with its `X` window in `memory.ts` and the write path in `write.ts`), `periph/`
(`periph/*`, the LCD branch: the HD44780 module — bus side in `hd44780.ts`, the pure controller
in `hd44780-controller.ts`, glass wiring per size in `hd44780-modules.ts`, the frame and text in
`hd44780-frame.ts`, the character ROMs generated from the data sheet into `hd44780-font.ts` by
`scripts/extract-hd44780-font.ts`; LIB-2's ST7789 TFT module — the serial interface, timing
checks and reset in `st7789.ts`, the pure controller (commands, frame memory, waits, the veil)
in `st7789-controller.ts`, the panels' windows in `st7789-panels.ts`, the glass in
`st7789-frame.ts`), `cpu/` (`cpu/*`, R17a: the W65C02S — the pins in
`w65c02s.ts`, the pure cycle-level core in `w65c02s-core.ts`, the opcode table in
`w65c02s-opcodes.ts`, the SingleStepTests runner in `single-step.ts` and its sample generated by
`scripts/sample-65c02.ts`), `draw/` (`draw/*`, PLT-1: graphics — the schematic text, its box
estimated from its lines in `text.ts`) and `registry.ts` (`createDefaultRegistry()`). One part per file (or one factory file for a
family of near-identical parts, like `primitives/gates.ts`), with a colocated `*.test.ts` built
from the datasheet function table. Recipe: `.ai/workflows/add-component.md`.

- **Depends on:** `core`.
- **Pure:** no DOM, no React. Drawing code lives in `editor`; the library only describes geometry.

Spec: [docs/components.md](../../docs/components.md).
